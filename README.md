# Noble Motors

Sitio web desarrollado como parte de una práctica del curso de Front-End de EBAC.

## Descripción

Noble Motors es un sitio web responsivo orientado a la presentación de vehículos y servicios automotrices.

El proyecto fue desarrollado utilizando HTML, CSS/SCSS y JavaScript, aplicando buenas prácticas de estructura, diseño responsivo y control de versiones con Git y GitHub.

## Tecnologías utilizadas

- HTML5
- CSS3
- SCSS
- JavaScript
- Git
- GitHub

## Características

- Diseño responsivo
- Navegación adaptable a diferentes tamaños de pantalla
- Secciones estructuradas semánticamente
- Formulario de contacto
- Diseño orientado a una empresa automotriz
